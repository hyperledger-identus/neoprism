# Bundled UI font provenance

These unmodified TrueType fonts are self-hosted by NeoPRISM. Both families
are distributed under the SIL Open Font License 1.1; the complete upstream
copyright and license notices accompany them in this directory.

## Poppins

Source: [Google Fonts, `ofl/poppins`][poppins], pinned to revision
`7af0d90b4d532ffa4b041937b560c6df4e7b1e95`.

- `Poppins-Regular.ttf`: weight 400
- `Poppins-Medium.ttf`: weight 500
- `Poppins-SemiBold.ttf`: weight 600
- Upstream `OFL.txt` is included unchanged as `Poppins-OFL.txt`.

## JetBrains Mono

Source: [JetBrains Mono, `fonts/ttf`][jetbrains], pinned to revision
`19371302b95d218af43299bce79ddbddd0bc364d`.

- `JetBrainsMono-Regular.ttf`: weight 400
- `JetBrainsMono-Medium.ttf`: weight 500
- Upstream root `OFL.txt` is included unchanged as `JetBrainsMono-OFL.txt`.
